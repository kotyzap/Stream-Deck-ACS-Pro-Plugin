The others are suggestions: assign the same combo once in AXIS Camera Station (F2 → Hotkeys, click the keyboard field, press the combo), or type here whatever your ACS already uses. Format: Ctrl+Shift+F5, keys Ctrl / Alt / Shift, A–Z, 0–9, F1–F12, Space, Tab, Esc, Enter, arrows, Plus, Minus. The hotkey is sent to the front window — use the Activate ACS key first. On a Mac it goes into Parallels / VMware / Remote Desktop, where ⌃ Control arrives as Ctrl.
